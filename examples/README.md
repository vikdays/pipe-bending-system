# Демонстрационные данные

Пока файлы примеров не созданы. Папки предназначены для полностью вымышленных данных:

- `tasks` — задания, которые экспортирует ПК и импортирует планшет.
- `results` — сеансы и подтверждённые измерения для возврата на ПК.
- `configurations` — явно демонстрационные снимки конфигураций, без утверждения производственных режимов.

При добавлении примеров нужно указать версию формата и единицы. Номера труб и документов — строки. Неизвестные значения — `null`.

Реальные Excel, сертификаты и базы помещайте в `local-data` или вне репозитория.
