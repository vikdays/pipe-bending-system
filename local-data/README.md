# Локальные материалы

Здесь можно держать реальные журналы Excel, сертификаты, рабочие файлы обмена и другие материалы для локального исследования. Они не являются исходным кодом.

Вложенный `.gitignore` исключает всё содержимое этой папки, кроме этого README и самого `.gitignore`. В GitHub попадут только эти два поясняющих файла. Не используйте `git add -f` для рабочих материалов.

Это удобная папка разработчика, а не утверждённый путь SQLite установленного приложения. Каждое приложение впоследствии будет хранить рабочую БД и вложения в собственной папке данных устройства. Игнорируемые файлы не копируются через Git; резервные копии нужно делать отдельно.
