# Общий код TypeScript

Пока это заготовки директорий, а не установленные библиотеки. `package.json` и подключения создадим вместе с первой общей реализацией.

- `domain/src` — предметные типы и правила, не зависящие от React Native, Wails, файловых диалогов или SQLite. Например, состояния сеанса и различие физического шага и повторного измерения.
- `contracts/src` — версия формата обмена, структура задания/результата и проверки входных данных. В TypeScript можно разделять эти проверки между мобильным приложением и настольным frontend.

Код этих пакетов не должен импортировать компоненты интерфейса или платформенные API. Go не исполняет TypeScript: чтение и сохранение в Go потребуют соответствующей проверки формата, а не предположения об автоматической переносимости кода.

Производственные формулы добавляются только после согласования методики.
